# Dev Stack

Dev Stack helps developers explore technologies and build a collection of tools for their next project.

## Technologies

- React
- TypeScript
- Vite
- Tailwind CSS

## Features

- Browse technology cards with descriptions, categories, badges, and ratings.
- Add technologies to your stack without adding duplicates.
- Remove individual technologies or clear the entire stack.
